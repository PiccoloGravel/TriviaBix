# Brain Blast

## Definition

Bix's network trivia show, 1996 to 2005, co-hosted by Brenda Sparks. Thursday nights at eight, then daytime, then Saturdays at six in the morning, then a knife infomercial.

## Usage Notes

Always written *Brain Blast!* with the exclamation mark in prose. In host lines, say it plainly ("Brain Blast") so text-to-speech doesn't shout it.
